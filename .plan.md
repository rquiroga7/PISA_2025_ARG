# Plan: PISA Argentina multi-year visualizer (2000–2025)

## Objective
Add a multi-year dimension to the PISA Argentina visualizer:
- A **year selector** for the existing 3-facet school scatter.
- A new **3-facet evolution line plot** below it (Matemática / Lectura / Ciencias).
- Everything fed by a **compact committed database** built from OECD microdata downloaded by a script.

All UI text in Spanish.

## Cycles
Argentina participated in: **2000, 2006, 2009, 2012, 2015, 2018, 2022, 2025** (not 2003).
- 2015: ARG sample had technical problems → data in the OECD "additional files" bundle.
- 2000: split into per-subject files + separate ESCS file.
- Comparability caveats: paper (≤2018) vs computer (2022+); ESCS rescaling; flagged 2015 sample.

## Database schema
`data/pisa_arg_schools.csv`:
`year, school_id, region, sector, n_stu, n_escs, escs, math, read, scie`
- Student-weighted means; PV mean-of-plausible-values; rescaled ESCS where applicable.
- `sector` ∈ {Pública, Privada, NR}; `region` best-effort (blank if unmapped).

`data/pisa_arg_trends.csv`:
`year, scope (ARG|OCDE), subject (math|read|scie), slope, intercept, r, n_schools, x_min, x_max`
- Student-count-weighted OLS at school level.

`data/pisa_arg_meta.json`: years, per-year flags/notes, sources, build timestamp.

## Region handling: best-effort mapping
- Detailed regions (CABA, Buenos Aires, Córdoba, Santa Fe, Mendoza, NOA, NEA, Cuyo, Patagonia)
  are encoded in cycle-specific `STRATUM` codes.
- 2025 mapping is known exactly (ARG01/02=CABA, ARG03/04=BsAs 24 partidos,
  ARG05/06=Resto BsAs, ARG07/08=Córdoba, ARG09/10=Santa Fe, ARG11/12=NEA,
  ARG13/14=NOA, ARG15/16=Cuyo, ARG17/18=Patagonia, ARG19/20=Mendoza; odd=Pública,
  even=Privada).
- `inspect_strata.py` dumps each cycle's strata + value labels; `region_mapping.json`
  is curated from that. Unmapped strata → blank region (renders as gaps).
- Documented as best-effort in the README; UI shows a note.

## Page (generated, Spanish)
- Controls: **Año**, **Región**, **Gestión**, **Ajuste**, **Restablecer**.
- Top: 3-facet scatter for the selected year (region colors, sector symbols ●/▲,
  size ∝ N, hover with school detail).
- Bottom: 3-facet evolution line plot (x = año, y = puntaje) for the current
  Región+Gestión selection; selected year highlighted; gaps for missing years.
- Ajuste: "Tendencia ARG" (per year, from DB), "Tendencia OCDE" (from trends table),
  "Tendencia seleccionados" (live OLS over visible schools).
- Data embedded as compact JSON arrays; traces built client-side to keep HTML small.

## Risks / open items
- **OECD membership by cycle** — curated membership-by-year table; changes affect
  historical trend lines.
- **Comparability** — paper vs computer mode, ESCS rescaling, flagged 2015 ARG sample.
- **Region mapping** is best-effort; early cycles may lack detailed strata → gaps.
- CABA participated as a subnational system in 2015; inclusion decided via mapping table.
